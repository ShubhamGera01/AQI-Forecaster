ABOUT THE PROJECT

Making Air Quality Data More Understandable

AQI Forecaster is an academic machine learning project focused on next-day air quality forecasting for Delhi. It combines historical time-series features, machine learning regression models and data visualization to demonstrate how predictive analytics can support environmental awareness.
